# Signa

Frontend de uma plataforma SaaS para operação de digital signage, construído com Next.js, TypeScript e Tailwind CSS.

## Executar

```bash
npm install
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Estrutura

- `src/app`: rotas e estilos por área
- `src/components`: shell, elementos de interface e páginas compostas
- `src/data`: mocks realistas para navegação
- `src/types`: contratos de domínio
- `src/lib`: utilitários compartilhados

As interfaces estão preparadas para futura integração com API, autenticação e RBAC.
